# Радиальное меню — версия на Rust

Перенос Python-версии (ветка `python-version`) на Rust: тот же внешний вид и логика
(стеклянные кнопки в стиле Actions Ring, веер подменю, подписи, громкость колесом, заметка
для Obsidian), но без Python/tkinter/Pillow — один `exe` около 1 МБ.

Зажми боковую кнопку мыши (по умолчанию «назад») — в центре экрана появится меню. Курсор стоит
на месте, меню управляется движением мыши: направление от центра выбирает блок. Колесо — громкость.
Отпусти кнопку — выполнится подсвеченный пункт, отпустил в центре — отмена.

## Сборка и запуск (Windows)

```
cd rust
cargo build --release          # RadialMenu.exe — в target\release
cargo test                     # тесты переносимого ядра (идут и на Linux/macOS)
```

Параметры командной строки (действуют только на этот запуск): `--button 1|2`, `--vault ПУТЬ`.
Постоянные настройки — `%APPDATA%\RadialMenu\config.txt` (создаётся при первом запуске):
`button`, `vault`, `sens_percent`, `size_percent`, `dwell_ms`.
Значок в трее: «Пауза», «Запускать с Windows», «Выход». Ошибки пишутся в `%TEMP%\RadialMenu_error.log`.

## Архитектура

Ядро не знает про Windows — это даёт тесты и предпросмотр без неё, а платформа остаётся тонкой.

| Слой | Модули | Что делает |
|---|---|---|
| данные | `menu`, `action`, `config` | дерево меню (арена, `enum`-ы вместо замыканий), действия как данные, настройки |
| логика | `geom`, `metrics`, `layout`, `nav`, `anim`, `style`, `engine` | раскладка, выбор по углу/задержке/гистерезису, анимации, кадр |
| графика | `raster`, `compose` | предрисовка масок (tiny-skia) при старте и программный композитор BGRA с «грязным» прямоугольником |
| заметки | `notes` | индекс хранилища, подсказки `[[ссылок]]`, безопасная запись Ring_NN.md |
| платформа | `platform/*` (только Windows) | хук мыши и Raw Input, окно-слой, SendInput, звук, окно заметки, трей |

Как добавить пункт меню: правится только `default_menu()` в `src/menu.rs`; новое действие — вариант
`Action` + ветка в `platform/input.rs`; новая иконка — файл в `assets/icons` + строка в `assets.rs`.

## Что сделано для экономии ресурсов

* **Простой = ноль.** Главный поток спит в `MsgWaitForMultipleObjectsEx`; кадровый таймер заводится
  только пока меню на экране. Опрос громкости идёт только на открытом меню (нет фонового потока).
* **Без картинок в кадре.** Кнопка — одна маска (тень/круг/обводка, ~80 КБ) + маски иконок;
  цвет и состояния смешиваются прямо при композитинге, поэтому нет набора «состояние × иконка».
* **Обновляется только изменённое.** Композитор считает «грязный» прямоугольник, окно обновляется
  через `UpdateLayeredWindowIndirect` с этим прямоугольником; частота кадров — по частоте монитора.
* **Шрифт живёт только при старте:** подписи рисуются заранее, потом шрифт выгружается.
* Хук мыши — отдельный поток, колбэк трогает только атомики (ответ в микросекундах).

## Улучшения относительно Python-версии

* Меню появляется на мониторе, где нажали кнопку; размеры учитывают DPI.
* Отпускание «чужой» боковой кнопки не глотается; сторож «зависшей» кнопки и переустановка хука сохранены.
* Заметка: индекс хранилища строится в фоне (большие хранилища не подвешивают окно), список подсказок
  и Ctrl+Enter/Esc/Tab/стрелки — как раньше; сохранение не затирает существующие файлы.
* SVG-иконки рисуются настоящим растеризатором (правила nonzero/evenodd, антиалиасинг), тень — честный гауссов блюр.
* Автозапуск и пауза из трея; настройки в файле.

## Проверка

Логика (навигация, раскладка, анимация, растеризация, композитор, заметки) покрыта тестами и выполняется на
любой ОС. Предпросмотр кадров в PNG: `cargo run --release --example preview -- папка` (`SCALE=1.5` — другой масштаб).
Сам Windows-слой (хук, окна, трей) проверен только компиляцией под `x86_64-pc-windows-gnu`; на живой системе
его нужно прогнать вручную по списку ниже.

### Ручная проверка на Windows

1. Запуск: значок в трее, второй запуск exe молча выходит (один экземпляр).
2. Зажать боковую «назад»: меню появляется в центре монитора с курсором, курсор не двигается, кнопки появляются по очереди.
3. Вверх/вправо/вниз/влево — подсветка блока; «Открыть» раскрывает веер сразу, «Вставить»/«Копировать» — после ~0,45 с.
4. Отпустить на «Вставить» — вставка (Ctrl+V); в центре — отмена; колесо при открытом меню — громкость и подпись.
5. «Медиа» зеленеет и пишет «играет», пока звучит аудио; «Пауза/Плей» переключает.
6. «Заметка»: окно по центру, набор `[[` → `[[]]` и список; стрелки/Enter/Tab/клик подставляют ссылку; Ctrl+Enter сохраняет Ring_NN.md; Esc закрывает.
7. Трей: «Пауза» возвращает обычную работу боковой кнопки; «Выход» убирает значок и процесс.
8. Через RDP меню работает по координатам (курсор возвращается на место нажатия).
